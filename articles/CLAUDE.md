## 上下文

## 职责
保存完整、原创、有来源的澳洲养老新闻博客 Markdown 草稿。

## 规则
- 每天最多一篇，以 Australia/Brisbane 日期命名。
- 优先近 24–48 小时新闻，必要时扩展至 7 天并标明日期。
- 必须打开核实来源，区分事实、推断、政策提案与生效状态。
- 文章头部保留 Owner、Status、Last reviewed；待人工审核，不自动发布。
- 不覆盖已有文件或人工编辑，不编造新闻、临床事实、效果数字或案例。
- 无足够新且可核实新闻时如实报告，不凑稿。

## 验收
文章完整可读，来源可追溯，营销及 TGA 边界自审完成；保存本地不代表 GitHub 发布。
